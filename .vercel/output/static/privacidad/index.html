2. Datos que recopilamos

Este sitio web no dispone de formularios de contacto ni sistemas de registro. La comunicación se realiza a través de WhatsApp y teléfono, canales externos gestionados por sus respectivas plataformas.

Los datos que podamos recibir a través de estos canales (nombre, número de teléfono, información sobre el tatuaje deseado) se tratarán exclusivamente para gestionar tu consulta o cita.

3. Finalidad del tratamiento

Los datos personales que nos facilites serán tratados con las siguientes finalidades:

  • Responder a consultas sobre tatuajes, micropigmentación o piercings.
  • Gestionar citas y reservas.
  • Comunicaciones relacionadas con el servicio contratado (seguimiento post-tatuaje).

4. Base legal

El tratamiento de tus datos se basa en:

  • Consentimiento: al contactarnos voluntariamente a través de WhatsApp o teléfono.
  • Ejecución de contrato: para la prestación del servicio de tatuaje solicitado.
  • Obligación legal: cumplimiento de obligaciones fiscales y sanitarias.

5. Conservación de datos

Los datos personales se conservarán durante el tiempo necesario para cumplir con la finalidad para la que fueron recogidos y, posteriormente, durante los plazos legalmente establecidos.

6. Cesión de datos

No se cederán datos personales a terceros salvo obligación legal. Este sitio web utiliza servicios de terceros:

  • Google Fonts: para la carga de tipografías.
  • Google Maps: para mostrar la ubicación del estudio.

También tienes derecho a presentar una reclamación ante la Agencia Española de Protección de Datos (www.aepd.es).

8. Seguridad

Coyote Tattoo adopta las medidas técnicas y organizativas necesarias para proteger los datos personales frente a su alteración, pérdida o acceso no autorizado.
